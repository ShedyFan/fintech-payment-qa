# Наивный прогон

Нужен для сравнения: что модель выдаёт на один короткий промпт **без спеки и без
правил проекта** против результата, собранного по `SPEC.md` и `AGENTS.md`.

## Как воспроизвести

1. Открыть **чистую сессию** агента (новый чат, без истории этого проекта) в
   пустой папке — так, чтобы `CLAUDE.md` / `AGENTS.md` этого репозитория не
   подхватились.
2. Отправить ровно один промпт — содержимое `prompt.txt`, дословно, без
   уточнений и дозапросов.
3. Сохранить ответ целиком в `test-plan-naive.md` рядом с этим файлом.
4. Записать в журнал сессии: дата, инструмент и модель, что именно было
   отправлено.

## Что потом

В `REPORT.md` — раздел «Сравнение двух прогонов»: конкретикой, не «стало лучше».
Ориентиры для сравнения:

- сколько сценариев, разбиты ли по областям;
- покрыты ли границы в деньгах: минус, ноль, копейки, округление, смешение
  валют, переполнение лимита;
- есть ли негативные и ошибочные сценарии, какая доля;
- заметил ли наивный прогон неоднозначности (пороги лимитов, режим округления,
  окно отмены) или молча выбрал за нас трактовку;
- есть ли раздел открытых вопросов;
- где наивный прогон оказался не хуже или быстрее — это тоже фиксируется.

## Что нельзя

Не удалять `prompt.txt` и `test-plan-naive.md` после прогона — без сохранённого
наивного результата сравнение нечем подтвердить (`AGENTS.md`, раздел «Что нельзя
трогать»).
