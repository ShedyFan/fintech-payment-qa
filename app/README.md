# app — платёжный кабинет (система под тестом)

Одностраничное учебное приложение: баланс, перевод с расчётом комиссии, дневной
лимит, отмена последней операции в окне, история. Один `index.html`, без сборки,
данные в `localStorage`.

Собрано за один проход по `build-brief.md`, без ручной доводки после — чтобы
тест-план проверял реальный продукт, а не вылизанный демонстрационный.

## Как запустить

```bash
# из корня репозитория
python -m http.server 8765
# открыть в браузере:
#   http://localhost:8765/app/index.html
```

Порт 8765 фиксирован (нужен для Playwright/браузерного агента — `file://` он не
открывает). Другой порт не выдумывать.

## Проверка, что поднялось

- Страница отвечает `200`, заголовок вкладки — «Платёжный кабинет».
- В консоли браузера нет ошибок при загрузке.
- Базовый сценарий: перевод 1000 ₽ получателю → баланс 50 000.00 → 48 990.00
  (комиссия 10.00 ₽, попадает в минимум), в истории одна строка со статусом
  «Исполнен» и кнопкой «Отменить».

## Заложенные правила

| Параметр | Значение |
|---|---|
| Начальный баланс | 50 000.00 ₽ |
| Комиссия | 1% от суммы, минимум 10.00 ₽, максимум 300.00 ₽ |
| Дневной лимит | 100 000.00 ₽ суммарно по переводам за день |
| Окно отмены | 60 секунд с момента создания операции |
| Хранилище | `localStorage`, ключ `payments-cabinet-v1` |

## Известно, что не задано (точки для тест-плана)

- Правило округления комиссии, когда 1% даёт больше двух знаков.
- Ограничение длины поля «Получатель».
- Как считается «сегодня» для дневного лимита на стыке суток.
- Защита от двойной отправки (двойной клик по «Перевести»).
- Ограничение размера истории операций.
