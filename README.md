заданию: тест-план по платёжным сценариям финтех-продукта (переводы, лимиты, карты,
комиссии, отмена операции).

несколькими параллельными агентами, с независимой проверкой и с попыткой сломать
собственную работу.

## Структура репозитория

```
.
├── README.md              — этот файл
├── test-plan.md           — сводный тест-план (после сведения трёх областей)
├── test-areas/            — черновики по каждой области до сведения
│   ├── transfers.md       — переводы и лимиты
│   ├── cards.md           — карты и отмена операции
│   └── fees.md            — комиссии, округление, граничные значения
├── workflows/
│   └── qa-regression-workflow.md   — повторяемая процедура прогона проверок
├── sessions/               — журнал сессий (промпты дословно, решения)
├── REPORT.md               — отчёт: что сделано, что не сработало
└── docs/                    — печатные версии: test-plan.pdf и report.pdf
                               (+ исходники вёрстки *.html и сборщик build-pdf.py)
```

## Как посмотреть работу

1. Тест-план целиком — `test-plan.md`.
2. Как собирался тест-план — по коммитам и по `sessions/`.
3. Отчёт по всем пунктам задания — `REPORT.md`.
4. Печатные версии — `docs/test-plan.pdf` и `docs/report.pdf`.

## Почему этот вариант

Взят вариант A4 из приложения к заданию — тест-план платёжных сценариев. Область
понятна без дополнительного контекста, естественно разбивается на независимые части
