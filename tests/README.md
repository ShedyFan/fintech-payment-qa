# tests — автотест продукта `app/`

- `payments.spec.js` — быстрый Playwright-сценарий против `app/index.html`
  (9 тестов, ~7 сек).
- `payments.slow.spec.js` — медленный: APP-011 с **реальным** ожиданием
  60+ секунд. Не входит в `npm test`; запуск — `npm run test:slow`.

## Как запустить

```bash
# 1. поднять продукт
python -m http.server 8765

# 2. в отдельном терминале, из корня репозитория
npm install                 # ставит @playwright/test (см. package.json)
npx playwright install chromium
npm test                    # быстрый набор  (tests/payments.spec.js)
npm run test:slow           # APP-011 вживую, ~65 сек (tests/payments.slow.spec.js)
```

### Медленный набор — `npm run test:slow`

| Тест | Результат | Комментарий |

| APP-011 (live) | PASS (wall ~65 с) | перевод → кнопка есть → **ждём 30 с** → кнопка ещё есть (таймер идёт) → **ждём ещё 33 с** → кнопки нет; операция «Исполнен», баланс `48990.00` не откатился |

Красных тестов на текущей версии `app/` нет — после фиксов BUG-01/02/03/04 все
девять быстрых зелёные, плюс медленный APP-011. APP-001/005/007 — регрессионная
страховка базового поведения, APP-003/008/009/011/012/014 — регрессия по
фикс-сессиям и граничные сценарии.

APP-008/011/012 в быстром наборе закрыты через seed-состояние `localStorage`
(`createdAt` в прошлое, `day` — на МСК-дату) — без ожидания реальных 60 секунд
и без ручного DevTools. То же поведение APP-011 подтверждено вживую в медленном
наборе.

`storedState()` в спеке сделан null-safe (AUDIT-07) — прежнее «Замечание по
спеке» про `TypeError` в `APP-005` закрыто.
