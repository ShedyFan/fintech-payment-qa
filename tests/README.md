# tests — автотест продукта `app/`

`payments.spec.js` — Playwright-сценарий против `app/index.html`.

## Как запустить

```bash
# 1. поднять продукт
python -m http.server 8765

# 2. в отдельном терминале, из корня репозитория
npm init -y
npm i -D @playwright/test
npx playwright install chromium
npx playwright test tests/payments.spec.js
```

Playwright и Node в окружении сборки этого репозитория не установлены —
прогон делает автор. Ожидаемый результат прогона на текущей версии `app/`
(после фикс-сессии BUG-01 от 2026-08-28):

| Тест | Ожидаемо | Почему |
| --- | --- | --- |
| APP-001 перевод 1000 | PASS | базовый сценарий работает |
| APP-005 нулевая сумма | PASS | валидация суммы работает; `storedState` теперь null-safe (AUDIT-07) |
| APP-007 нехватка средств | PASS | проверка баланса работает |
| **APP-003 [BUG-01 fixed]** округление комиссии | **PASS** (было FAIL) | фикс: `fee = 12.35`, `balance = 48753.09`; см. `sessions/2026-08-28-fix-bug-01.md` |
| **APP-009 [BUG-03]** разделитель разрядов | **FAIL** | `1 000` по-прежнему сохраняется как `1`, ошибка не показана — BUG-03 не чинился |
| **APP-014 [BUG-04]** битая схема в localStorage | **FAIL** | `{"balance":0,"operations":[{}]}` роняет `renderHistory` (`TypeError`) — BUG-04 не чинился |

Красными держат требование «тест падает на найденном дефекте» APP-009 (BUG-03) и
APP-014 (BUG-04). APP-003 позеленел после фикса BUG-01; APP-001/005/007 —
регрессионная страховка. После фиксов BUG-03 и BUG-04 красных остаться не должно.

`storedState()` в спеке сделан null-safe (AUDIT-07) — прежнее «Замечание по
спеке» про `TypeError` в `APP-005` закрыто.
