# tests — автотест продукта `app/`

`payments.spec.js` — Playwright-сценарий против `app/index.html`.

## Как запустить

```bash
# 1. поднять продукт
python -m http.server 8765

# 2. в отдельном терминале, из корня репозитория
npm install                 # ставит @playwright/test (см. package.json)
npx playwright install chromium
npm test                    # = npx playwright test tests/payments.spec.js
```
