- **`docs/build-pdf.py`** (AUDIT-08) — переносим: Chromium ищется по списку
  кандидатов Windows/macOS/Linux + `shutil.which` + `CHROME_BIN`; временная
  папка — системный temp; автор титула — `PDF_AUTHOR`. Только Python 3 (stdlib).
  AUDIT-08 снят.
- **`docs/paged.polyfill.js`** (~921 КБ) в репозитории — намеренно, но раздувает
  клон (AUDIT-14).
- Ветки `cards`/`fees`/`transfers` и каталоги worktree после merge не удалены
  **на исходной машине автора**; в `origin` они не отражены. Свежий клон
  (в т.ч. `F:\AI\fintech-payment-qa`) их не содержит: `git branch -a` — только
  `main`, `git worktree list` — только основная копия, `git stash list` пуст.
  По репозиторию видны лишь три merge-коммита — это ожидаемо, чистить в
  публичной версии нечего.
- Прогон регрессии 2026-08-27 устарел (95 сценариев; области позже расширены,
  повторно не гонялись); шаг 4 регрессии 2026-08-28 — самопроверка без отдельного
  агента.
- `CRD-029` — дефектный сценарий (ожидаемый результат без проверяемого оракула),
  не переписан.
- `.gitignore` правился дважды из-за `/dev/null`-заглушек конфигов в песочнице.
- Логи субсессий теста инъекции (Haiku/Opus) в `sessions/` не сохранены —
  в `REPORT.md` § 6 только таблица и выдержки (дословный ответ для вектора 1).
